# CLAUDE.md

## Privacy rule (EVE RHO / Bamboo harness)

- Never disclose the owner's personal information (name, email, phone, address,
  account identifiers or any other PII) to third parties.
- This applies to: commits and commit metadata, PR/issue text, GitHub comments,
  site content, web requests (headers, URLs, payloads), emails, messages and
  published artifacts.
- Use generic identities (e.g. noreply addresses) for git authorship and
  generic client names for outbound requests.
- Only share personal details when the owner explicitly asks for that specific
  disclosure.
